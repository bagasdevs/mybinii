# mybinii

Pick K-pop girl groups, narrow the field through heats, rank your 9 favourites by
pairwise comparison, then download the result as a PNG poster.

Live: https://mybinii.pages.dev/

Extras compared with the site that inspired it: **search** (Korean names and
romanisations) and **i18n** (한국어 / English / Bahasa Indonesia).

Progress is saved to `localStorage`: a reload lands back on the same heat board
or the same pairwise comparison, and every phase has a way back to setup.

## Run it

No build step, no dependencies. The page uses ES modules, so it must be served
over HTTP rather than opened as `file://`:

```bash
python -m http.server 8080 --directory .
# open http://localhost:8080/
```

## Test

```bash
node --test
```

Requires Node 26+. Tests use the built-in runner; no framework.

## Deploy

Upload this folder as-is to Cloudflare Pages (drag & drop, or
`npx wrangler pages deploy .`). There is no `node_modules` and no build output.
Make sure `photos/` is uploaded too.

## Layout

```
data/roster.json       source data (80 groups, 475 members)
data/roster.js         generated by tools/build-roster.mjs
i18n/ko.js en.js id.js UI dictionaries
js/i18n.js             locale picker + interpolation          [pure]
js/search.js           normalise + index + query               [pure]
js/game.js             tournament + merge sort                 [pure]
js/view.js             HTML helpers                            [pure]
js/state.js            one state object + every action
js/render.js           per-phase dispatch
js/phases/*.js         render for each phase
js/poster.js           1080x1600 canvas poster
js/photo.js            crop + upload dialog
js/credits.js          credits dialog
```

Modules marked `[pure]` never touch the DOM and are tested directly in Node.

## Adding a language

1. Copy `i18n/ko.js` to `i18n/<code>.js` and translate the values.
2. Add the language code to `LOCALES` in `js/i18n.js`.
3. Import and register the dictionary in `js/main.js`.

Nothing else. `test/i18n-keys.test.mjs` fails if any key is left untranslated.

## Updating the data

```bash
node tools/build-roster.mjs    # after editing data/roster.json
node tools/mirror-photos.mjs   # download new photos, verify sha256
node --test
```

## Known limitations

- **Korean group names are incomplete.** 50 of 79 groups only carry a Latin name
  (`TWICE`, `aespa`, `BLACKPINK`, …), so searching `트와이스` finds nothing — use
  `twice`. Korean member names do work: in the heat phase, `나연` finds TWICE.
  Adding Korean aliases means adding a small map in `js/view.js` (same shape as
  `EN_GROUP_OVERRIDES`) and feeding that label into the group index.
- **Uploaded photos are not saved.** Progress (phase, picks, comparisons) is
  restored from `localStorage`, but photos you swapped in live as blob URLs and
  are gone after a reload — the poster falls back to the default photos.
- **Photo files are large.** 475 mirrored JPEG/PNG files, no thumbnails and no
  AVIF/WebP, so mobile data use is noticeable.
